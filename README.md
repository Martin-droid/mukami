# Mukami Galaxy React Experience

A React + Vite single-page experience celebrating Mukami with an interactive galaxy canvas, floating planets, and a heartfelt memory log. Designed to deploy cleanly on Vercel.

## Getting Started

```bash
npm install
npm run dev
```

The development server will start on port 5173.

## Production Build

```bash
npm run build
npm run preview
```

The build output lives in the `dist` folder and is configured for seamless deployment on Vercel (see `vercel.json`).
